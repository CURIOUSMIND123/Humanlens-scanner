An honest question
"If the content is free, why do we need you?"
  • The free content is scattered and online-only — not arranged for a classroom.
  • We make it work offline on the board, for schools with no internet.
  • We map it to the syllabus — class by class, chapter by chapter.
  • We build the software — the board, the school system, the command centre.
  • We add local languages, our own lessons, install, train and service.
  • One partner, one accountability — and the State owns it all.
